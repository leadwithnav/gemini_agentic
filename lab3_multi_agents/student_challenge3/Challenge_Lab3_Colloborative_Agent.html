Collaborative Multi-Agent Exchange Assistant

Understand how a supervisor agent collaborates with specialized peer agents to solve complex user inquiries.

🤝 Collaborative Swarm Pattern
Instead of hardcoded Python workflow loops or single-agent tool dispatching, a Supervisor Agent understands user intent, delegates work to specialized sub-agents, reasons across their findings, and outputs a consolidated final response.
Swarm Delegation Architecture 
Example Request: "Tell me about NYMEX and also list the products available on it."

                    Supervisor (root_agent)
                   /                      \
                  /                        \
      Exchange Info Agent            Product List Agent
      (get_exchange_details)         (list_products_by_exchange)
                  \                        /
                   \                      /
                    Supervisor (root_agent)
                               │
                               ▼
                        Final Response

Step 1: Review Specialist Peer Agents

Understand single-turn specialist agent contracts and focused tool assignments.

🎯 Specialist Peer Contracts
• exchange_info_agent: Focuses ONLY on exchange details (name, location, description) using get_exchange_details.
• product_list_agent: Focuses ONLY on product symbol catalog using list_products_by_exchange.
Specialist Agent Definitions (agent.py) 
exchange_info_agent = Agent(
    name="exchange_info_agent",
    model=MODEL_NAME,
    description="Provides general information about CME Group exchanges.",
    instruction="""Identify exchange code, call get_exchange_details, return EXCHANGE FINDINGS.""",
    tools=[get_exchange_details],
)

product_list_agent = Agent(
    name="product_list_agent",
    model=MODEL_NAME,
    description="Finds product symbols associated with a CME Group exchange.",
    instruction="""Identify exchange code, call list_products_by_exchange, return PRODUCT FINDINGS.""",
    tools=[list_products_by_exchange],
)
  • Inspect Specialist Descriptions Verify that both specialists include clear `description` fields so the supervisor knows when to delegate to them.

Step 2: Supervisor Delegation Rules

Understand how the supervisor agent routes sub-tasks to specialists.

👑 Supervisor Instructions & Delegation
The supervisor LLM inspects user requests against the `description` and `instruction` of all registered `sub_agents`. When a query requires multiple capabilities, it delegates to specialists in sequence or parallel and synthesizes the final response.
Supervisor Collaboration Instructions 
root_agent = Agent(
    name="collaborative_exchange_assistant",
    model=MODEL_NAME,
    instruction="""You are the CME Exchange Support Supervisor.
COLLABORATION RULES:
- Delegate exchange-information work to exchange_info_agent.
- Delegate product-list work to product_list_agent.
- If the request requires BOTH types of information, collaborate with BOTH specialists.
- After receiving specialist findings, return one concise consolidated response.""",
    sub_agents=[...],
)
  • Review Collaboration Rules Understand how the supervisor delegates sub-tasks without calling raw tools directly.
