Demo 1A: The Tool Semantics Demonstration

Instructor Demo: Prove why vague tool descriptions cause Gemini selection failures.

❌ POOR TOOL SEMANTICS (INSTRUCTOR BAD EXAMPLE)
Tool descriptions are NOT human documentation—they are Gemini's API prompt.
A vague function name like get_data with docstring "Gets data." causes Gemini to fail parameter extraction or skip the tool entirely.
Python: Bad Tool Example 
# POOR TOOL SEMANTICS DEMO
def get_data(value: str):
    """Gets data."""
    return PRODUCTS.get(value.upper(), "Not found")

# Ask Gemini: "What is the contract size of ES?"
# Result: Gemini struggles to infer parameter intent and fails tool execution.
✅ REFACTORED GOOD TOOL SEMANTICS
Adding explicit type hints (`symbol: str`), a descriptive docstring, and Google-style parameter docs fixes Gemini tool selection immediately!
Python: Refactored Good Tool 
def get_product_details(symbol: str) -> dict:
    """Retrieve contract specifications and details for a futures product using its ticker symbol.

    Args:
        symbol: Futures ticker symbol such as ES, NQ, CL, GC, 6E, or ZC.
    """
    clean_symbol = symbol.strip().upper()
    if clean_symbol in PRODUCTS:
        result = dict(PRODUCTS[clean_symbol])
        result["found"] = True
        return result
    return {"found": False, "symbol": clean_symbol, "message": f"Product '{clean_symbol}' not found."}

Demo 1A: Root Agent & Enterprise Rules

Instantiate root_agent with Google ADK and register system instructions.

Python: cme_agent/agent.py 
from google.adk.agents import Agent
from .tools import get_product_details, get_market_status, list_products_by_asset_class

SYSTEM_INSTRUCTION = """
You are an internal CME Market Product Support Agent.

RESPONSIBILITIES:
- Explain basic futures product information and contract sizes.
- Identify product asset classes and simulated market statuses.

TOOL POLICY:
- Always use available tools for factual information. Never invent product data or market status.

SAFETY:
- Strictly READ-ONLY informational agent.
- NEVER execute, place, modify, or cancel trades under any circumstances.
"""

root_agent = Agent(
    name="cme_market_support_agent",
    model="gemini-2.5-flash",
    description="Internal CME Market Product Support Agent.",
    instruction=SYSTEM_INSTRUCTION,
    tools=[get_product_details, get_market_status, list_products_by_asset_class]
)

Challenge 1B: Reference Solution

Review the completed solution code and architecture for Challenge 1B.

Python: student_challenge_1b/solution_agent.py 
from google.adk.agents import Agent
from ..cme_agent.data import PRODUCTS

def get_product_details(symbol: str) -> dict:
    """Retrieves full descriptive metadata and contract specification for a futures product by symbol."""
    clean_symbol = symbol.strip().upper()
    if clean_symbol in PRODUCTS:
        result = dict(PRODUCTS[clean_symbol])
        result["found"] = True
        return result
    return {"found": False, "symbol": clean_symbol, "message": f"Product '{clean_symbol}' not found."}

def get_market_status(symbol: str) -> dict:
    """Retrieves the current simulated trading status (OPEN or CLOSED) for a CME market product."""
    clean_symbol = symbol.strip().upper()
    if clean_symbol in PRODUCTS:
        return {"found": True, "symbol": clean_symbol, "status": PRODUCTS[clean_symbol]["trading_status"]}
    return {"found": False, "symbol": clean_symbol, "message": f"Product '{clean_symbol}' not found."}

def list_products_by_asset_class(asset_class: str) -> list:
    """Lists all available CME market products belonging to a specified asset class."""
    clean_ac = asset_class.strip().lower()
    return [dict(p) for p in PRODUCTS.values() if clean_ac in p["asset_class"].lower()]

solution_agent = Agent(
    name="solution_product_support_agent",
    model="gemini-2.5-flash",
    description="Refactored CME Product Support Agent for Challenge 1B.",
    instruction="You are an internal CME Market Product Support Agent. Read-only informational support.",
    tools=[get_product_details, get_market_status, list_products_by_asset_class]
)
