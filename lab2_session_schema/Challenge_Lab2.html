Task 2: Exchange Resolver Agent & `output_key`

Capture agent text output directly into session state for inter-agent communication.

🔑 Understanding `output_key`
Setting output_key="some_key" on an ADK Agent tells the framework to automatically save that agent's final text response into ctx.state["some_key"].
This allows exchange_resolver to output an exchange symbol (e.g. NYMEX) and pass it seamlessly to downstream agents!
