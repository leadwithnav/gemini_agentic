Part 5.1: CME Incident Management REST API

📋 REST API Endpoints (Port 8001)
Underlying REST microservice routes serving incident data:
HTTP Method Endpoint Route Query / Path Params Description & Status Code
GET /health None Returns {"status": "UP"} (HTTP 200)
GET /incidents None Returns all support incidents (HTTP 200)
GET /incidents?symbol=NQ symbol (str) Filters incidents by normalized product symbol (HTTP 200)
GET /incidents/{incident_id} incident_id (str) Returns metadata for specific incident or HTTP 404 Not Found

Part 5.2: CME Incident MCP Server (Port 8002)

🛠️ Exposed MCP Tools
The MCP server wraps REST API calls into clean, business-level LLM tools:
  • get_incident_by_id(incident_id: str) → calls GET http://127.0.0.1:8001/incidents/{incident_id}
  • get_incidents_by_symbol(symbol: str) → calls GET http://127.0.0.1:8001/incidents?symbol={symbol}
MCP Server Implementation (integrations/incident_mcp/server.py) 
import httpx
from mcp.server.mcpserver import MCPServer

REST_API_BASE_URL = "http://127.0.0.1:8001"
HTTP_TIMEOUT = 5.0

mcp = MCPServer("CME Incident Management MCP Server")

@mcp.tool()
def get_incident_by_id(incident_id: str) -> dict:
    """Retrieve details for a specific CME incident by its unique ID (e.g., 'INC-101')."""
    normalized_id = incident_id.strip().upper()
    print(f"[MCP] get_incident_by_id called incident_id={normalized_id}", flush=True)
    try:
        with httpx.Client(timeout=HTTP_TIMEOUT) as client:
            resp = client.get(f"{REST_API_BASE_URL}/incidents/{normalized_id}")
            if resp.status_code == 200: return resp.json()
            if resp.status_code == 404: return {"found": False, "error": f"Incident '{normalized_id}' not found"}
            return {"found": False, "error": "Incident service unavailable"}
    except Exception:
        return {"found": False, "error": "Incident service unavailable"}

@mcp.tool()
def get_incidents_by_symbol(symbol: str) -> dict:
    """Retrieve all CME incidents associated with a specific trading product symbol (e.g., 'NQ', 'ES')."""
    normalized_symbol = symbol.strip().upper()
    print(f"[MCP] get_incidents_by_symbol called symbol={normalized_symbol}", flush=True)
    try:
        with httpx.Client(timeout=HTTP_TIMEOUT) as client:
            resp = client.get(f"{REST_API_BASE_URL}/incidents", params={"symbol": normalized_symbol})
            if resp.status_code == 200: return resp.json()
            if resp.status_code == 404: return {"found": False, "error": f"No incidents found for symbol '{normalized_symbol}'"}
            return {"found": False, "error": "Incident service unavailable"}
    except Exception:
        return {"found": False, "error": "Incident service unavailable"}

if __name__ == "__main__":
    mcp.run(
        transport="streamable-http",
        host="127.0.0.1",
        port=8002,
        streamable_http_path="/mcp",
    )

Google ADK McpToolset Configuration (cme_agent/tools.py)

ADK McpToolset Definition (lab5_mcp_agents/cme_agent/tools.py) 
from google.adk.tools.mcp_tool import McpToolset, StreamableHTTPConnectionParams

# Connect ADK agents to the Streamable HTTP MCP Server on port 8002
mcp_connection_params = StreamableHTTPConnectionParams(
    url="http://127.0.0.1:8002/mcp"
)

# Instantiate ADK McpToolset wrapping remote MCP Server
incident_mcp_toolset = McpToolset(
    connection_params=mcp_connection_params
)
