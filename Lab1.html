Step 2: Standardized Tool Response Contract

Enforce consistent JSON payload contracts across all Python agent tools.

📘 The Tool Response Contract Specification
Success Standard:
{"status": "success", "data": {...}, "error": null, "is_simulated_data": true}

Error Standard:
{"status": "error", "data": null, "error": {"code": "PRODUCT_NOT_FOUND", "message": "..."}, "is_simulated_data": true}
Python: cme_agent/tools.py 
from .data import PRODUCTS

def get_product_details(symbol: str) -> dict:
    """Retrieve descriptive and contract specifications for a CME futures product by ticker symbol.

    Args:
        symbol: Futures ticker symbol such as ES, NQ, CL, GC, ZC, or 6E.
    """
    clean_symbol = symbol.strip().upper()
    if clean_symbol in PRODUCTS:
        return {
            "status": "success",
            "data": dict(PRODUCTS[clean_symbol]),
            "error": None,
            "is_simulated_data": True
        }
    return {
        "status": "error",
        "data": None,
        "error": {
            "code": "PRODUCT_NOT_FOUND",
            "message": f"Product '{clean_symbol}' was not found in the simulated market dataset."
        },
        "is_simulated_data": True
    }

Step 3: Root Agent & System Instructions

Instantiate root_agent with Google ADK using structured system sections.

Python: cme_agent/agent.py 
from google.adk.agents import Agent
from .tools import get_product_details, get_market_status, list_products_by_asset_class

SYSTEM_INSTRUCTION = """
ROLE:
You are an internal CME Market & Product Support Agent.

RESPONSIBILITIES:
- Retrieve product specifications, contract sizes, and asset classes.
- Retrieve simulated market status (OPEN / CLOSED).
- List products for requested asset classes.

TOOL USAGE RULES:
- Always use available tools for factual product queries. Inspect tool response 'status' and 'data'.
- Never invent product details or market availability.

BOUNDARIES:
- Strictly READ-ONLY informational agent.
- NEVER execute, place, modify, or cancel trades under any circumstances.

ERROR HANDLING:
- If a tool returns status='error', explain the error message clearly to the user.
"""

root_agent = Agent(
    name="cme_market_support_agent",
    model="gemini-2.5-flash",
    description="Internal CME Market & Product Operations Agent.",
    instruction=SYSTEM_INSTRUCTION,
    tools=[get_product_details, get_market_status, list_products_by_asset_class]
)
