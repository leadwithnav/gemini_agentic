Lab 4 Student Challenge: BigQuery Integration

Connect Google ADK V2 to real enterprise BigQuery datasets (cme_support.exchanges and cme_support.exchange_products) using BigQueryToolset.

📊 Enterprise BigQuery Architecture
Instead of in-memory Python dictionaries, exchange information is now stored in Google BigQuery. You must provision the BigQuery tables using biggquery_script.sh, configure read-only BigQueryToolset in bigquery_tools.py, and register tools on agents in agent.py.
