Step 1: ADK LLM Configuration & Performance Tuning Concepts

Learn how to fine-tune Gemini model generation parameters using Google GenAI SDK's GenerateContentConfig for deterministic routing and optimized specialist responses.

💡 Why LLM Hyperparameter Tuning Matters
By default, LLMs operate under general-purpose generation parameters. In high-performance agentic systems:
  • Classification Agents require zero temperature (temperature=0.0) and tight token bounds (max_output_tokens=128) to ensure fast, deterministic routing.
  • Specialist Agents require low temperature (temperature=0.1) for domain accuracy and specific token limits (max_output_tokens=512) to prevent runaway verbosity.
  • Thinking Controls (ThinkingConfig) can reduce latency by setting thinking_level=MINIMAL and disabling thought logging for production APIs.
Classifier Config Low Latency

Optimized for deterministic routing and quick JSON extraction.

  • temperature: 0.0 (Strict determinism)
  • top_p: 0.8
  • max_output_tokens: 128
  • thinking_level: MINIMAL
Specialist Config Domain Accurate

Optimized for clean tool calling and structured customer answers.

  • temperature: 0.1 (High fidelity)
  • top_p: 0.9
  • max_output_tokens: 512
  • thinking_level: MINIMAL
Python • config/llm_config.py 
from google.genai import types

CLASSIFIER_LLM_CONFIG = types.GenerateContentConfig(
    temperature=0.0,
    top_p=0.8,
    max_output_tokens=128,
    thinking_config=types.ThinkingConfig(
        thinking_level=types.ThinkingLevel.MINIMAL,
        include_thoughts=False,
    ),
)

SPECIALIST_LLM_CONFIG = types.GenerateContentConfig(
    temperature=0.1,
    top_p=0.9,
    max_output_tokens=512,
    thinking_config=types.ThinkingConfig(
        thinking_level=types.ThinkingLevel.MINIMAL,
        include_thoughts=False,
    ),
)

Step 4: Side-by-Side Benchmark & Comparative Analysis

Compare performance, determinism, token consumption, and response structure between Default and Tuned LLM Configs.

Dimension Default LLM Config (agent_default_config.py) Tuned LLM Config (agent_with_config.py)
Classifier Temperature Model Default (~1.0 / stochastic) 0.0 (Strictly Deterministic)
Classifier Token Limit Unbounded (Default generation limit) 128 Tokens (Tight JSON ceiling)
Specialist Temperature Model Default (~1.0) 0.1 (High fidelity domain answers)
Specialist Token Limit Unbounded 512 Tokens (Concise response guarantee)
Thinking Overhead Default reasoning tokens included MINIMAL (include_thoughts=False)
Routing Reliability Possible variations across runs 100% Consistent Schema Extraction
🚀 Key Architectural Takeaways
  1. Zero Temperature for Routers: Always use temperature=0.0 when an agent extracts structured output (Pydantic / JSON) or performs flow routing.
  2. Token Ceiling Protection: Bounding classifier output tokens to 128 prevents runaway hallucination or unnecessary preamble text before JSON.
  3. ThinkingLevel Optimization: Setting thinking_level=ThinkingLevel.MINIMAL speeds up classification turnaround while preserving full LLM capabilities for tool selection.
