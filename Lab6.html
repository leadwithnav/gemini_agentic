Lab 6: Enterprise ADK Callbacks, Observability & Security Governance

Master Agent & Tool lifecycle interception, Role-Based Access Control (RBAC), latency observability, and SQL guardrails in Google Agent Development Kit (ADK).

💡 Why Lifecycle Callbacks Matter in Enterprise AI
In production enterprise agentic systems, AI models cannot execute arbitrary database queries or external actions without strict runtime governance.
ADK Callbacks act as zero-trust middleware that sit directly between the Gemini model, sub-agent workflows, and database tools to enforce permission checks, block unauthorized SQL execution, and track execution latency.

System Architecture

👑
CME Support Supervisor
Collaborative supervisor agent that analyzes user queries and delegates tasks to domain specialist agents before synthesizing final responses.
🔍
Product Support Agent
Specialist for CME contract sizes, symbols, asset classes, and support owners using Dynamic Schema Discovery.
📊
Market Status Agent
Specialist for trading status, market closures, and status reasons using Static Schema Prompting.
🛡️
Security & Guardrail Callbacks
Intercepts every tool invocation to validate user permissions (RBAC), enforce SELECT-only SQL policies, and log execution latency.

ADK Interception Flow

Gemini Model / Supervisor Agent │ │ [Delegates work / tool call request] ▼ before_agent_callback / before_tool_callback │ ├── 1. Latency Start Timer (time.perf_counter) ├── 2. User Authorization (RBAC: alice/bob vs guest) └── 3. SQL Business Guardrails (SELECT only, ALLOWED_TABLES) │ ├───► [BLOCKED] --> Return standardized error dictionary immediately │ ▼ [PASSED] BigQuery / Tool Execution │ ▼ after_tool_callback / after_agent_callback │ ├── Calculate Execution Latency (duration_ms) └── Record Observability State (ctx.state) │ ▼ Synthesized Result to User

Step 2: Agent Lifecycle Callbacks

Understand `before_agent_callback` and `after_agent_callback` in `callbacks/callback_agents.py`.

⚙️ Agent Event Hooks
Agent callbacks execute when an ADK agent starts (`before_agent_callback`) and completes (`after_agent_callback`). They receive a CallbackContext object providing metadata such as `agent_name`, active state, and execution history.

Implementation (`cme_agent/callbacks/callback_agents.py`)

Simple Agent Callbacks - Lab 6

from typing import Optional
from google.adk.agents.callback_context import CallbackContext
from google.genai import types


# ============================================================
# BEFORE AGENT CALLBACK
# ============================================================

def before_agent_callback(
    callback_context: CallbackContext,
) -> Optional[types.Content]:

    agent_name = callback_context.agent_name
    print(f"\n[AGENT START] {agent_name}")
    return None


# ============================================================
# AFTER AGENT CALLBACK
# ============================================================

def after_agent_callback(
    callback_context: CallbackContext,
) -> Optional[types.Content]:

    agent_name = callback_context.agent_name
    print(f"\n[AGENT END] {agent_name}")
    return None

Step 3: Tool Security Governance & Guardrails

Implement RBAC permission checks, SQL business guardrails, and latency observability in `callbacks/callback_tools.py`.

🛡️ Security & Interception Pattern
If before_tool_callback returns a dictionary (e.g., {"status": "BLOCKED", "error": "..."}), Google ADK aborts tool execution immediately and passes the block response back to Gemini, preventing unauthorized or unsafe operations!

Tool Callback Pipeline (`cme_agent/callbacks/callback_tools.py`)

Python: callback_tools.py 
import time
import logging
from typing import Dict, Any, Optional
from google.adk import Context

# SIMULATED ROLE-BASED ACCESS CONTROL (RBAC)
AUTHORIZED_USERS = {
    "alice": True,
    "bob": True,
    "guest": False,
}

# APPROVED TABLES GUARDRAIL
ALLOWED_TABLES = {"PRODUCTS", "MARKET_STATUS", "INCIDENTS"}

def block(error_message: str) -> Dict[str, Any]:
    return {"status": "BLOCKED", "error": error_message}

def check_permission(tool_name: str, ctx: Context) -> Optional[str]:
    user_id = ctx.state.get("user_id")
    user_authorized = AUTHORIZED_USERS.get(user_id, False)
    if not user_authorized:
        return f"User '{user_id}' is not authorized."
    return None

def check_business_guardrails(tool_name: str, args: Dict[str, Any], ctx: Context) -> Optional[str]:
    args_dict = args or {}
    sql = args_dict.get("query", "").strip().upper()

    # Guardrail 1: Enforce SELECT-only queries
    if not sql.startswith("SELECT"):
        return "Only SELECT queries are allowed."

    # Guardrail 2: Enforce query on approved tables only
    if not any(table in sql for table in ALLOWED_TABLES):
        return f"Only these tables are allowed: {sorted(ALLOWED_TABLES)}"

    return None

# BEFORE TOOL INTERCEPTION
def before_tool_callback(tool: Any, args: Dict[str, Any], tool_context: Context) -> Optional[Dict[str, Any]]:
    tool_name = getattr(tool, "name", str(tool))
    tool_context.state[f"tool_start_time:{tool_name}"] = time.perf_counter()

    perm_err = check_permission(tool_name, tool_context)
    if perm_err:
        return block(perm_err)

    guard_err = check_business_guardrails(tool_name, args, tool_context)
    if guard_err:
        return block(guard_err)

    return None

# AFTER TOOL LATENCY OBSERVABILITY
def after_tool_callback(tool: Any, args: Dict[str, Any], tool_context: Context, tool_response: Any) -> Optional[Dict[str, Any]]:
    tool_name = getattr(tool, "name", str(tool))
    start_time = tool_context.state.get(f"tool_start_time:{tool_name}")
    if start_time:
        duration_ms = (time.perf_counter() - start_time) * 1000
        tool_context.state["last_tool_duration_ms"] = duration_ms
    return None

Step 4: Collaborative Multi-Agent Routing Setup

Instantiate specialists, configure supervisor routing, and attach callbacks in `cme_agent/agent.py`.

Python: cme_agent/agent.py 
from google.adk import Agent, Workflow, Context
from .tools.bigquery_tools import bigquery_toolset, DATASET_ID, PROJECT_ID
from .callbacks.callback_tools import before_tool_callback, after_tool_callback
from .callbacks.callback_agents import before_agent_callback, after_agent_callback

MODEL = "gemini-2.5-flash"

# 1. Product Support Specialist (Dynamic Schema Discovery)
product_support_agent = Agent(
    name="product_support_agent",
    model=MODEL,
    mode="single_turn",
    description="CME specialist for product details, contract specs, asset class, currency.",
    instruction="Access `{PROJECT_ID}.{DATASET_ID}.products` using get_table_info and execute_sql.",
    tools=[bigquery_toolset],
    before_agent_callback=before_agent_callback,
    after_agent_callback=after_agent_callback,
    before_tool_callback=before_tool_callback,
    after_tool_callback=after_tool_callback,
)

# 2. Market Status Specialist (Static Schema)
market_status_support_agent = Agent(
    name="market_status_support_agent",
    model=MODEL,
    mode="single_turn",
    description="CME specialist for trading status, market closures, status reasons.",
    instruction="Access `{PROJECT_ID}.{DATASET_ID}.market_status` (schema: symbol, trading_status, status_reason).",
    tools=[bigquery_toolset],
    before_agent_callback=before_agent_callback,
    after_agent_callback=after_agent_callback,
    before_tool_callback=before_tool_callback,
    after_tool_callback=after_tool_callback,
)

# 3. Collaborative Supervisor Agent
supervisor_agent = Agent(
    name="cme_support_supervisor",
    model=MODEL,
    description="Supervisor coordinating product and market status specialists.",
    instruction="Understand user request, delegate work, and synthesize findings.",
    sub_agents=[product_support_agent, market_status_support_agent]
)

# Save original user request & state
def save_original_request(ctx: Context, node_input: str) -> str:
    ctx.state["original_request"] = node_input
    ctx.state["PROJECT_ID"] = PROJECT_ID
    ctx.state["DATASET_ID"] = DATASET_ID
    ctx.state["user_id"] = "guest"  # Toggle to 'alice' to pass authorization
    return node_input

root_agent = Workflow(
    name="part3_4_support_routing",
    edges=[("START", save_original_request, supervisor_agent)],
)
