Lab 5 Challenge: Integrating Google ADK with MCP & BigQuery

Build a Hybrid CME Exchange Support Agent using Model Context Protocol (MCP) for Exchange Information and Google BigQuery for Product Information.

🎯 Challenge Objective
In this hands-on lab, you will configure Google ADK to talk to a remote MCP Server running over Streamable HTTP while simultaneously preserving a direct enterprise BigQueryToolset integration.

Main New Learning Objective: Complete the MCP client configuration in Google ADK. BigQuery integration is already fully completed in the starter code and does NOT require any student modifications.

System Architecture

The system uses a Request Classifier and Router to direct incoming CME support requests down two distinct enterprise integration paths: 

                                  User
                                   │
                                   ▼
                           Request Classifier
                                   │
                                   ▼
                                 Router
                                   │
       ┌───────────────────────────┴───────────────────────────┐
       ▼                                                       ▼
 EXCHANGE_INFO                                           PRODUCT_INFO
       │                                                       │
       ▼                                                       ▼
Exchange Info Agent                                     Product Info Agent
       │                                                       │
       ▼                                                       ▼
   McpToolset                                           BigQueryToolset
       │                                                       │
       ▼                                                       ▼
   MCP Server                                               BigQuery
       │                                                       │
       ▼                                                       ▼
    REST API                                     cme_support.exchange_products
💡 Architecture Key Principles
  • Exchange Info Agent: Uses McpToolset to consume tools exposed by the remote MCP Server.
  • MCP Server: Encapsulates the underlying FastAPI REST service, hiding REST endpoints and HTTP logic from Google ADK.
  • Product Info Agent: Directly queries Google Cloud BigQuery analytical tables (cme_support.exchange_products) via ADK's native BigQueryToolset.
  • Student Scope: You only need to complete the MCP-related TODOs in tools.py and agent.py.

Key Architectural Takeaways

📌 Summary: MCP as an Integration Boundary
1. Decoupled Tool Protocols: Model Context Protocol (MCP) serves as a standardized integration boundary. ADK Agents operate strictly on high-level business tool definitions, while MCP Servers encapsulate backend infrastructure choices (REST APIs, HTTP endpoints, auth schemes).

2. Hybrid Data Architectures: Modern AI platforms combine standardized protocol integration (MCP for microservices and external tools) with native high-performance toolsets (ADK BigQueryToolset for enterprise data warehouses).

3. Production Flow Summary:
• Exchange Information: Agent → McpToolset → MCP Server → REST API
• Product Information: Agent → BigQueryToolset → BigQuery
